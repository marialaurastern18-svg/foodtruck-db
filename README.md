Foodtruck DB

Proyecto de base de datos desarrollado con PostgreSQL y DBeaver.
El proyecto consiste en el diseño de un modelo relacional para la gestión de food trucks, incluyendo información sobre productos, pedidos, detalle de pedidos y ubicaciones.
Se crearon las tablas correspondientes y se establecieron claves primarias y claves foráneas para definir las relaciones entre los datos.
Estructura del Proyecto
Data: Contiene los archivos csv utilizados.
Scripts: Contiene los scripts SQL correspondientes a la creación y modificación del esquema de la base de datos.
